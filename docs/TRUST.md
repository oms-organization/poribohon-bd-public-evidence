# Public Trust & Verification Model

This repository is designed to make public project and identity claims easier to verify, not to manufacture authority.

## Trust principles

1. **Primary sources first** — Prefer the live official website, its public provenance/identity pages, official public profiles, and the project's own release/test records.
2. **Independent properties remain distinct** — PoribohonBD, OMS IT, BD AI, OMS Nexus, and NFF Bangladesh are documented as separate public identities. A link between them is not treated as proof of ownership or legal affiliation unless the primary evidence explicitly supports that claim.
3. **No synthetic authority** — This repository does not claim Google ranking, AI recognition, government authority, awards, certifications, endorsements, partnerships, reviews, or backlinks unless independently verified.
4. **Reproducible evidence** — Verification records should identify the public URL, the type of evidence, and the verification date where practical.
5. **No private evidence** — Credentials, secrets, private user information, production database exports, and sensitive infrastructure details are excluded.
6. **Corrections are preferred to persistence** — If a public claim becomes outdated or contradicted by primary evidence, this documentation should be corrected rather than defended.

## Identity verification approach

For an identity/name to be treated as a verified public identity in this repository, there should be a matching primary public property such as an official website, official profile, or an explicit structured-data/provenance statement. Similar names alone are not sufficient.

## Source hierarchy

**Highest confidence:**
- Official production website
- Official provenance/identity page
- Official structured data published by that property

**Supporting evidence:**
- Official public social profile
- Public GitHub organization/repository controlled by the project
- Reproducible build, test, or release record

**Not sufficient by itself:**
- Search snippets
- Unverified third-party pages
- Screenshots without a verifiable source
- Claims copied between unrelated sites
