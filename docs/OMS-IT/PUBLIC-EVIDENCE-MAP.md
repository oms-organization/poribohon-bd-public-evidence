Public evidence should distinguish:

- OMS IT as the engineering/technology organization.
- BD AI as a separately identifiable initiative with a documented technology/operational support relationship with OMS IT where applicable.
- PoribohonBD as its own project/initiative with its documented engineering attribution.
- Md Mahadi Hassan as a person-level technical contributor/representative only where the relevant public source supports that attribution.

## Evidence hierarchy

Prefer official websites, canonical machine-readable identity endpoints, public repositories, reproducible tests/results, deployment evidence and authoritative published records. If evidence is unavailable, mark the item as unverified/source-waiting rather than filling the gap with inference.

## Private boundary

Private repositories and private engineering documents remain the source of truth for confidential implementation details. This public map must never be used as a route to credentials, secrets, private source code, customer data, confidential agreements, internal network information or sensitive operational logs.
