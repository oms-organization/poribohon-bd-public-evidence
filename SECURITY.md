# Security

This repository is intentionally limited to public, non-sensitive documentation and evidence.

## Never publish

- API keys, access tokens, passwords, or private keys
- Authentication/session secrets
- Production database exports or credentials
- Private personal information
- Internal infrastructure credentials or sensitive topology
- Private GitHub Actions secrets

## Reporting

Potential security issues in the production application should not be disclosed by publishing sensitive details in this repository. Use the project's established private security/contact channel instead.

## Scope

The public evidence repository does not represent the security architecture of the private production system in full. It records only information that is intentionally safe to publish.
