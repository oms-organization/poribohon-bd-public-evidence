# OMS IT — Public Surface Index

This index describes where an external reviewer or AI/search system should look for public OMS IT facts.

## Primary identity surfaces

- Official website: https://omsitbd.com/
- GitHub organization: https://github.com/oms-organization

## Public evidence surfaces

- Public project evidence repositories
- Project websites and official project pages
- Public documentation and machine-readable identity pages
- Public verification/evidence pages where a project provides them

## Project relationship surfaces

For each project, the public record should expose:

- project identity
- official URL
- purpose and scope
- OMS IT role, if publicly documented
- project owner/initiative identity where documented
- relationship type
- evidence/provenance source
- current status
- limitations and claim boundaries

## Person and credential surfaces

Where a person is publicly attributed, the record should distinguish:

- person identity
- role/title
- organization context
- project context
- professional/technical attribution
- independently verifiable credentials or records

## Machine-readable surfaces

Where available, use canonical pages, JSON-LD, sitemap, robots rules, llms.txt, and public JSON identity/evidence endpoints. These surfaces should contain only information intentionally published for external discovery.

## Private boundary

The private OMS IT repository remains private. A public surface is a curated evidence/index layer, not a mirror of private source code, private notes, internal logs, secrets, customer data, or internal infrastructure.
