# OMS IT — Public Reports, Verification & Clearance Index

This is an **index of evidence categories**, not a publication of private audit reports or internal clearance records.

## Publicly useful report categories

- Identity / brand verification
- Project provenance and technology attribution
- Architecture and engineering verification
- Testing and QA evidence
- Security and privacy verification
- Deployment / release verification
- SEO, canonical and machine-readable identity verification
- Relationship / ownership-boundary verification
- AI-provider and third-party technology clarification
- Public readiness / status records
- Historical closure and continuity records

## Publication rule

When a report has been intentionally made public, publish its title, date/version, scope, status and public reference. If the underlying report is private, do **not** publish its private findings merely because the heading is useful for discovery.

## Clearance rule

A private engineering clearance, internal test count, production approval, founder decision, or internal certification is not automatically public evidence. Public wording must match a public source.

## Continuity rule

If a future decision changes a relationship, status, project role, credential, or public claim, update the public index first with the exact new evidence and effective status. Do not rely on old cached descriptions.
