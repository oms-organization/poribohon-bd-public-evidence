# Public Discoverability

This repository is designed to provide a stable, public, non-sensitive evidence surface that search engines, researchers, developers, and AI-assisted search systems can discover.

## Canonical public sources

- PoribohonBD: https://poribohonbd.com/
- PoribohonBD provenance: https://poribohonbd.com/provenance
- OMS IT: https://omsitbd.com/
- BD AI: https://bdaihelp.com/
- OMS Nexus: https://omsnexus.app/
- NFF Bangladesh: https://nffbd.org/

## What this repository provides

- Project identity and scope
- Public technology attribution
- Public verification and testing records
- Release evidence where available
- Security/privacy boundaries
- Links to canonical public properties

## What it does not claim

This repository does not guarantee Google indexing, search ranking, AI-system recognition, citations, backlinks, authority, endorsement, partnership, government status, awards, certifications, or legal registration.

## Source-of-truth principle

The production website and its own public provenance/structured-data records remain the primary sources for product facts. This repository is a documentation companion and must not contradict or overstate those sources.

## Keeping the record trustworthy

Updates should be made when genuine project changes or verified public evidence occur. Do not add fabricated activity, reviews, traffic, rankings, backlinks, partnerships, certifications, or social profiles for discoverability purposes.
