# OMS IT — Public Project Index

This section is reserved for projects that have an intentional public evidence surface.

Each project entry should expose only:

- public project name
- official public URL
- public purpose/scope
- OMS IT role, when verified
- public evidence/provenance links
- status that can be independently verified

Private project plans, source code, credentials, customer data, internal logs, and confidential delivery material do not belong here.
