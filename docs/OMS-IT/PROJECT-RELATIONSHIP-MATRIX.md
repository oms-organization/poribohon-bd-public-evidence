## Interpretation rule

The matrix is intentionally conservative. If a future public source establishes a more specific relationship, update the exact cell and add the source. Do not replace an evidence-backed relationship with an inferred one.

## Relationship vocabulary

Prefer these explicit terms where applicable:

- owner
- operator
- independent initiative
- engineering support
- technology support
- operational support
- consultant / consulting role
- technical attribution
- integration
- third-party technology
- project / initiative

Do not use ambiguous umbrella terms such as “partner”, “affiliate”, “subsidiary”, “official representative”, “government project”, or “endorsed by” unless the public evidence explicitly supports that term.
