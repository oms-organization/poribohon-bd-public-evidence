## Brand rule

Use the exact canonical name and relationship type supported by the relevant public evidence. Do not collapse distinct entities into one brand merely because they share engineering, technology, personnel, infrastructure or AI tooling.

## Verification chain

1. Official organization or project website.
2. Canonical public machine-readable identity surface.
3. Public GitHub evidence and project documentation.
4. Other authoritative published records.
