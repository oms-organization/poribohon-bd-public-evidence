# Scope

This public repository documents the publicly supportable scope of PoribohonBD.

## In scope

- Public website and publicly described platform purpose
- Publicly visible features and service descriptions
- Public verification and testing summaries
- Public release/provenance records
- Public technology attribution that is explicitly documented by the project

## Out of scope

- Production application source code
- Private repositories
- Credentials, tokens, API keys, or secrets
- Production database exports
- Private user or customer information
- Internal infrastructure details that are not intentionally public
- Unsupported claims about ranking, authority, partnerships, certifications, government status, or third-party recognition

## Source principle

Evidence should come from the live public PoribohonBD site, the public GitHub repository history available for this evidence repository, or other independently verifiable public records. When a fact cannot be verified, it should not be presented as established fact.
