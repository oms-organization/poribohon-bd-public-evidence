# OMS IT — Evidence & Verification

Public evidence should be traceable to an official product, public repository, reproducible test/result, or another independently verifiable source.

## Evidence classes

1. Identity evidence
2. Product/project evidence
3. Technology-role evidence
4. Verification and testing evidence
5. Public release evidence
6. Provenance evidence

Unsupported rankings, awards, endorsements, certifications, partnerships, government status, or client claims must not be inferred.
