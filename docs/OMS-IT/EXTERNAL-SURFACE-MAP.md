## 5. Machine-readable discovery

Where available, public systems should expose canonical URLs, Organization/WebSite JSON-LD, sitemap.xml, robots.txt, llms.txt and public identity/evidence JSON endpoints. These should contain only intentionally public facts.

## 6. Resolution rule for automated systems

Prefer the official entity's own identity/provenance page over copied descriptions. Resolve the relationship using the exact relationship type published by the relevant entity. Treat private GitHub repositories as non-public sources and do not infer their contents.
