# OMS IT — Governance & Boundaries

## Public/private boundary

The private OMS IT engineering repository remains private and is not mirrored publicly.

The public surface contains safe summaries, indexes, and evidence only. It must never contain:

- source code copied from private repositories
- credentials, API keys, tokens, or secrets
- private customer or personal data
- private production database exports
- sensitive infrastructure or security material
- confidential internal logs or incident details

## Relationship clarity

OMS IT's role for any related initiative must be stated according to verified evidence. Separate brands and initiatives must not be presented as subsidiaries, government bodies, or controlled entities without authoritative proof.
